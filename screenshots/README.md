# Screenshots Directory

This folder contains screenshots demonstrating the Spotter Fuel Route Optimizer application and its key functionality.

### Included Screenshots

1. `1_short_route_no_fuel_stop.png`
   Short-route example demonstrating a route within the vehicle's 500-mile range where no fuel stop is required.

2. `02_ny_chicago_single_fuel_stop.png`
   New York → Chicago route demonstrating a route longer than 500 miles with one optimized fuel stop, including fuel price, gallons purchased, and cost details.

3. `03_long_route_multiple_fuel_stops.png`
   Long-route example demonstrating multiple fuel stops selected along the route based on the 500-mile maximum vehicle range and fuel prices.

4. `04_long_route_api_calls.png`
   Long-route API demonstration showing the route, fuel-stop optimization, total fuel cost, and external API call count.

### What These Screenshots Demonstrate

* Route visualization on an interactive map
* Short and long route handling
* 500-mile maximum vehicle range
* Automatic fuel-stop selection
* Fuel-price-based optimization
* Multiple fuel stops for long routes
* Fuel quantity and cost calculation
* External routing API call efficiency
